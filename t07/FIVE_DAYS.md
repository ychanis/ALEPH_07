# 실제 5일 사용 기록 — 아직 미완료

테스트 계정의 자료는 실제 사용자 기록에 포함하지 않는다. 서로 다른 서울 날짜 정확히 5일을 실제로 사용한 후 이 문서를 완성한다. 날짜·학습시간·판단을 미리 채우지 않는다.

1. 가입·로그인하고 계정 설정에서 과제 6 소유자 확인과 기존 자료 연결을 한다.
2. 상단 ‘과제 7 · 5일 기록’에서 질문 한 문장과 계획 규칙 하나를 고정한다.
3. 각 실제 날짜에 집중 학습 시간(분)과 한 일을 기록한다. 서버가 오늘 날짜를 정한다.
4. 2일차 기록 뒤 3일차 기록 전에 계획 규칙 하나만 바꾼다. 이유를 직접 적는다.
5. 5일차 뒤 전체 내보내기를 하고 아래를 실제 값으로 채운다.

| 일차 | 실제 서울 날짜 | 집중 학습 시간(분) | 실제 한 일 |
|---|---|---|---|
| 1 | 미기록 | 미기록 | 미기록 |
| 2 | 미기록 | 미기록 | 미기록 |
| 3 | 미기록 | 미기록 | 미기록 |
| 4 | 미기록 | 미기록 | 미기록 |
| 5 | 미기록 | 미기록 | 미기록 |

- 고정한 질문: 미입력
- 처음 계획 규칙: 미입력
- 변경한 계획 규칙 한 가지: 미입력
- 변경 시각과 이유: 미입력
- 정확히 참조한 1·2일차 기록 ID: 내보낸 JSON에서 확인
- 직접 합계: 1~5일차 분을 더하기
- 직접 평균: 합계 ÷ 5, 소수점 첫째 자리로 반올림
- 변경 전 평균: (1일차+2일차) ÷ 2
- 변경 후 평균: (3일차+4일차+5일차) ÷ 3
- 화면과 직접 계산 대조: 미완료
- 비교·판단 한 문장: 실제 결과 확인 후 작성

누락은 0으로 보정하지 않는다. 같은 날짜 중복은 거절한다. 600분을 초과하면 실제 사유를 적고 0~1440분 실제값을 유지한다. 주 시작은 월요일이다.
