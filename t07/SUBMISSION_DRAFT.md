## 짧은 확인 방법 4줄

1. 어디로 가나요: 결과물 주소의 첫 로그인 화면과 공개 소스의 t07 인증 설명서로 갑니다.
2. 세 단계 안에 무엇을 하나요: 로그인 화면 확인 → 설명서의 ④ 확인 기록 열기 → 성공·거절 요청 쌍과 양방향 접근 차단 기록 비교.
3. 무엇이 보이면 통과인가요: 개인 기록이 공개되지 않는 로그인 화면, 성공 200과 거절 401/404 증거, 실제 5일 기록 및 규칙 변경·검산이 보입니다.
4. 안 될 때는 무엇이 보이나요: 비로그인은 로그인 화면·API 401, 남의 자료는 API 404, 실패한 입력은 오류 안내가 보이고 기록이 추가되지 않습니다.

## AI와 내 판단 3줄

1. AI에게 맡긴 일: 인증·자료 보호 기능 구현, 자동 요청 검증, 설명서 초안 작성.
2. 내가 직접 판단한 일: 실제 사용자가 선택한 질문·계획 규칙·변경 이유·결과 판단을 사용 후 직접 기재합니다.
3. AI 제안을 따르지 않은 일: 사용자가 직접 작성합니다. 없다면 결과와 증거를 확인하고 채택한 이유를 기재합니다.

실제 비밀번호·세션 쿠키·토큰·비밀키를 제출하지 않습니다. 심사자는 계정을 만들지 않고 첫 화면과 문서·증거를 읽어 확인할 수 있습니다.
